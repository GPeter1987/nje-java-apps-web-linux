Labdarúgó REST API

JSON alapú végpontok a játékosok lekérdezéséhez és kezeléséhez.

Végpontok

MetódusÚtvonalMűveletSikeres válasz
GET/api/labdarugokJátékosok listája200 OK
GET/api/labdarugok/{id}Egy játékos lekérése200 OK
POST/api/labdarugokÚj játékos létrehozása201 Created
PUT/api/labdarugok/{id}Játékos adatainak módosítása200 OK
DELETE/api/labdarugok/{id}Játékos törlése204 No Content

A POST és PUT kérések application/json tartalomtípust várnak. Hibás mező vagy ismeretlen klub/poszt esetén 400-as válasz érkezik, nem létező játékosnál 404.

Kérés törzse

{
  "mezszam": 99,
  "klubId": 1,
  "posztId": 9,
  "utonev": "Minta",
  "vezeteknev": "Játékos",
  "szulido": "2000-01-15",
  "magyar": true,
  "kulfoldi": false,
  "ertek": 100
}

A klub- és posztazonosítók a adatbázis oldalon látható csapatokhoz és posztokhoz tartoznak. Az érték ezer euróban értendő.

cURL példa

Lista lekérése

curl -i http://localhost:8080/nb1/api/labdarugok

Új játékos létrehozása

curl.exe -i -X POST http://localhost:8080/nb1/api/labdarugok -H "Content-Type: application/json" -d '{"mezszam":99,"klubId":1,"posztId":9,"utonev":"Minta","vezeteknev":"Játékos","szulido":"2000-01-15","magyar":true,"kulfoldi":false,"ertek":100}'

Játékos módosítása vagy törlése

curl.exe -i -X PUT http://localhost:8080/nb1/api/labdarugok/319 -H "Content-Type: application/json" -d '{"mezszam":10,"klubId":1,"posztId":9,"utonev":"Minta","vezeteknev":"Játékos","szulido":"2000-01-15","magyar":true,"kulfoldi":false,"ertek":125}'

curl.exe -i -X DELETE http://localhost:8080/nb1/api/labdarugok/319

A példák Windows parancssorból futtatható curl.exe-t használnak; Linux/macOS rendszeren a curl.exe helyett curl írandó.

Postman használata

  1. Hozz létre egy kérést, és válaszd ki a GET, POST, PUT vagy DELETE metódust.
  2. Állítsd be az URL-t a táblázat szerinti végpontra, például http://localhost:8080/nb1/api/labdarugok.
  3. POST és PUT esetén válaszd a Body → raw → JSON beállítást, majd illeszd be a fenti JSON-t.
  4. Kattints a Send gombra. A válaszkód és a JSON válasz a Postman alsó paneljén jelenik meg.

A teljes, importálható kérésgyűjtemény: NB I. labdarúgó API – Postman collection.

A helyi alkalmazás tesztadatai minden újraindításkor újratöltődnek; az API-n létrehozott rekordok tesztelés után törölhetők a DELETE kéréssel.
